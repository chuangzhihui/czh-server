# 目录结构（后台前端 czh-admin）

> 前端管理后台工程 `czh-admin/`（React 19 + TypeScript + Vite 7 + antd 6）的目录说明，
> 与《后台开发规范》（`md/后台开发规范.md`）§2 配套；后端目录见《服务端目录结构》（`md/服务端目录结构.md`）。
> 最近修订：2026-10-15

## 1. 工程总览

```
czh-admin/
├── public/            # Vite root：index.html、favicon、字体(iconfont)、第三方 js
│   ├── font/          #   iconfont 字体文件与样式
│   ├── js/            #   第三方 js（不参与构建）
│   └── index.html
├── src/               # 源码（全部在此）
├── .env.development   # 开发环境变量（VITE_API_URL=http://127.0.0.1:18081）
├── .env.production    # 生产环境变量
├── .env.test          # 测试环境变量
├── vite.config.js     # root=public，输出 ../dist
├── tsconfig.json      # strict: true，noEmit 仅做类型检查
└── package.json
```

## 2. src 目录（核心）

```
src/
├── api/               # 【接口 + 数据模型】统一目录，按模块聚合（无顶层 models/ 目录）
│   ├── admin/                 # 管理员模块（三件套）
│   │   ├── AdminApi.ts        #   该模块全部接口（纯接口，不写类型定义）
│   │   ├── AdminDto.ts        #   该模块入参类型（DTO）
│   │   └── AdminVo.ts         #   该模块返回实体（VO）
│   ├── role/                  # 角色模块（RoleApi/RoleDto/RoleVo）
│   ├── menu/                  # 菜单模块（MenuApi/MenuDto/MenuVo）
│   ├── set/                   # 参数配置 / 上传设置 / 安全配置（SetApi/SetDto/SetVo）
│   ├── backup/                # 数据库备份（BackupApi/BackupDto/BackupVo）
│   ├── login/                 # 登录 / 验证码（LoginApi/LoginDto/LoginVo）
│   ├── common/                # 通用（CommonApi/CommonVo：PageInfoVo / SelectVo）
│   └── ApiTypes.ts            # 跨模块通用入参（PageDto 等）
├── pages/             # 页面层：每个页面一个同名大驼峰目录，内含 index.tsx (+ index.scss)
│   ├── Login/                 # 平铺页面目录（独立功能页）
│   └── system/                # 业务域模块目录
│       ├── admin/   AdminList/ + AddAdmin/     # 列表页 + 新增/编辑弹窗
│       ├── role/    RoleList/ + AddRole/
│       ├── menu/    MenuSet/
│       ├── set/     BasicInfo/ + AddBasic/
│       └── ...      （AuthConfig/ SetColor/ UploadSet/ UserInfo/ DbBackUp/ 等为历史平铺页）
├── Route/             # 路由与菜单映射（src 根级，不在 pages 下）：index.tsx 的 Components 映射表
├── component/         # 通用组件：CZH* 前缀，每个组件一个同名大驼峰目录（index.tsx + index.scss）
│   ├── CZHTable/              # 分页表格（loading/分页/排序/虚拟滚动/高度自适应）
│   ├── CZHTableSearch/        # 列表页搜索区
│   ├── CZHModal/              # 纯展示弹窗 + FormModal（表单弹窗，含 .open() 静态方法）
│   ├── CZHSelect/             # 字典下拉（角色、管理员）
│   ├── CZHTitle/  CZHText/  CZHTableAction/
│   ├── CZHEditor/             # 富文本（wangEditor + 图片标注画布）
│   ├── CZHFileComponent/      # 文件库（上传、列表、缩略图、新建文件夹）
│   ├── Loading/  Page404/  ThreeBackground/
├── util/              # 工具
│   ├── request.ts             #   请求层唯一出口（httpPost/httpGet/httpBlob）
│   ├── Helper.ts / Validator.ts / ThemeUtil.ts / ThemeContext.ts
├── css/
│   ├── main.scss              # 唯一全局样式入口（reset + flex 骨架 + 响应式 + 通用类 + antd 覆盖）
│   └── _variables.scss        # 断点 / 间距 / 字体变量（局部私有，不产出 CSS）
├── static/            # 参与打包的本地图片（默认头像、文件类型图标）
├── types/             # 全局 d.ts（window.d.ts）
├── test/              # 测试配置（setup 等）
├── App.tsx            # HashRouter + antd App + Suspense
└── main.tsx           # ConfigProvider（主题 token）+ 挂载（唯一 import 全局样式处）
```

## 3. 关键判定规则

**页面归属判定（强制，二选一不得同层混用）**：

- **模块目录** `pages/system/<模块>/<页面>/`：业务域有列表页 + 新增/编辑弹窗（如 `admin/AdminList` + `admin/AddAdmin`）；
- **平铺页面目录** `pages/<页面>/`：独立功能页，无增删改查列表（如 `Login/`）。

**api 三件套（强制）**：一个模块 = 一个 `api/<模块>/` 子目录，固定 `Api`（纯接口）+ `Dto`（入参）+ `Vo`（返回）三件套；无入参模块可只建 Api + Vo。

**新增页面三步**：① `pages/system/<模块>/XxxList/index.tsx` → ② `src/Route/index.tsx` 的 `Components` 注册（key 大小写敏感）→ ③ 后台「菜单管理」配同 key 的 `path`。

**样式归属**：全局样式只有 `src/css/main.scss`；页面/组件样式就近建同名 `.scss`，且选择器必须锁在宿主根类下（见《后台开发规范》12.6）。

## 4. 不存在的目录（禁止新建）

| 目录 | 说明 |
|---|---|
| `src/models/` | 已废弃，数据模型并入 `api/<模块>/` 三件套 |
| `src/pages/Route/` | 路由表唯一位置是 `src/Route/index.tsx`（src 根级） |
| 第二个全局样式文件 | `global.css` / `common.css` / `App.css` / `index.css` 一律禁止 |
| 扁平组件文件 | 禁止 `component/CZHXxx.tsx`，必须 `component/CZHXxx/index.tsx` |
