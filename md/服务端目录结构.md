# 服务端目录结构

> 后端工程（Maven 多模块）目录说明，与《服务端开发规范》§3「分层架构与包约定」配套。
> 前端工程 `czh-admin` 的目录结构见《目录结构》（`md/目录结构.md`）。
> 最近修订：2026-10-15（按源码实际结构核实）

## 1. 工程总览

```
czh-server/
├── pom.xml                 # 父工程（packaging=pom，聚合 4 个模块，统一管理版本 revision=1.1.1）
├── common/                 # 公共基础模块
├── service/                # 数据服务模块
├── admin/                  # 管理后台接口模块（可执行 jar：CZH_admin.jar）
├── api/                    # 对外接口模块（可执行 jar：CZH_api.jar，当前基本为空壳）
├── czh-admin/              # 前端工程（非 Maven 模块，见《目录结构》）
├── sql/                    # 数据库脚本
└── md/                     # 规范文档
```

依赖方向单向向下：`common → service → { admin, api }`。

## 2. common（公共基础层）

```
common/src/main/java/com/czh/common/
├── annotation/             # 自定义注解
│   ├── Log.java            #   标记需记录操作日志的接口（LoggingAspect 落库）
│   └── Permission.java     #   声明接口权限校验及关联权限标识
├── config/                 # 公共配置
│   ├── AutoValidationAspect.java  # @RequestBody 自动校验切面（免 @Valid）
│   ├── CZHPasswordEncoder.java    # Spring Security 密码编码器
│   ├── ExecutorConfig.java        # 异步线程池
│   ├── PageHelperConfig.java      # 分页插件（admin/api 共用，启动类不再声明）
│   └── RedisConfig.java
├── dto/
│   └── PageDto.java        # 通用分页入参（page/size/orderBy）
├── exception/              # 自定义异常 + 全局异常处理器
│   ├── commonExceptionHandler.java  # @ControllerAdvice 全局兜底
│   ├── ErrorException.java / LoginFailException.java / NoAuthException.java
│   ├── NotLoginException.java / PasswordErrorException.java
├── utils/                  # 工具类
│   ├── SecurityUtil.java   #   取当前登录信息
│   ├── SensitiveUtil.java  #   敏感字段脱敏（password/pwd/token → ****）

└── vo/

    ├── EmptyVo.java / SelectVo.java
```

## 3. service（数据服务层）

```
service/src/main/java/com/czh/service/
├── cache/                  # 鉴权缓存（key 统一登记在 AuthCacheKeys）
│   ├── AdminAuthCache.java #   管理员鉴权视图（不含密码哈希）
│   └── AuthCacheKeys.java
├── dao/                    # MyBatis Mapper 接口（extends BaseMapper<T>，@Mapper）
│   ├── AdminDao.java / RoleDao.java / MenuDao.java / SettingDao.java
│   ├── AuthConfigDao.java / AdminActionLogDao.java / DbBackupDao.java
│   ├── UploadFilesDao.java / UploadSetDao.java / AreaDao.java
│   └── xml/                # 自定义 SQL 的 Mapper.xml（显式列名，禁 select *）
├── entity/                 # 数据库实体（DO），与表一一对应，不写 @TableName
├── service/                # 业务接口
│   └── impl/               # 业务实现（extends ServiceImpl<Dao, Entity>）
├── dto/admin/              # 入参对象（带约束注解，按业务子包划分）
└── vo/admin/               # 出参对象（按业务子包划分，禁止直接返回 Entity）
```

## 4. admin（管理后台接口）

```
admin/
├── src/main/java/com/czh/admin/
│   ├── AdminApplication.java
│   ├── baseController/         # ⚠️ 现状：业务 Controller 与框架基类混放
│   │   ├── BaseController.java     # 业务 Controller 共同父类（注入 RedisUtil 与常用 Service）
│   │   ├── ErrController.java      # /error 出口（HTTP 200 + body code 404，内容判别）
│   │   ├── UploadController.java   # 文件上传入口
│   │   ├── admin/    AdminController.java      # 管理员、登录信息、改密、操作日志
│   │   ├── role/     RoleController.java       # 角色管理
│   │   ├── menu/     MenuController.java       # 菜单管理
│   │   ├── setting/  SettingController.java    # 参数配置 / 上传设置 / 文件库 / 安全配置
│   │   ├── backup/   DbBackUpController.java   # 数据库备份
│   │   ├── login/    LoginController.java      # 登录、验证码、系统名
│   │   └── common/   CommonController.java     # 通用字典
│   ├── config/
│   │   ├── SecurityConfig.java   # Spring Security 配置（STATELESS）
│   │   ├── CorsFilter.java       # CORS 白名单回显（注册在 Security 链之前）
│   │   └── LoggingAspect.java    # 请求/操作日志切面（落库前走 SensitiveUtil 脱敏）
│   └── security/
│       ├── AdminDetails.java                 # UserDetails 实现
│       ├── AdminAuthenticationProvider.java  # 加载用户 + 验证码校验 + 失败计数
│       ├── JWTAuthFilter.java                # JWT 鉴权 + 权限判定（checkPermission）
│       ├── AdminAuthFailedHandler.java       # 401/403 下发（HTTP 200 + body code）
│       ├── AdminTokenService.java / CaptchaService.java
├── src/main/resources/
│   ├── application.yaml            # 主配置（spring.profiles.active、签名密钥、CORS 白名单）
│   └── application-dev/test/prod.yaml   # 多环境（端口：dev 18081 / test 8081 / prod 18093）
└── src/test/java/com/czh/admin/    # 单测（鉴权、脱敏、参数校验、回归用例）
```

> **目录演进说明（规范已定，代码未迁）**：《服务端开发规范》§3 已裁决将 `baseController/` 拆为
> **`controller/`（业务接口，可自由增删改）+ `framework/`（只放 BaseController 与 ErrController，改动需评审）**。
> 当前源码仍为 `baseController/` 混放形态，迁移属存量改造任务（批次 G，8 个文件机械移动、零逻辑改动）。
> 迁移完成前，新 Controller 仍放 `baseController/` 对应业务子包下。

## 7. 关键约定速查

| 约定 | 说明 |
|---|---|
| 根包 | `com.czh`，包名全小写 |
| 调用链 | `Controller → Service/Impl → Dao(Mapper) → Entity`；入参 DTO、出参 VO |
| 表名 | 实体不写 `@TableName`，靠全局 `table-prefix: czh_` 拼接 |
| 字段 | 数据库字段驼峰命名，与实体同名（`map-underscore-to-camel-case: false`） |
| Mapper.xml | 与 Mapper 同包 `dao/xml/`，namespace 指向全限定名 |
| 测试 | 沿用既有测试包 `com.czh.admin` / `com.czh.api`，不重复建包 |
